Standard 1: Three Ways to Apply CSS

An inline style is used to apply a unique style directly to a single HTML . Designers write the CSS code inside the HTML tag using the attribute. Because inline styles only affect one specific element on a page, they are generally inefficient for styling an entire website, but they are useful for quick, single-element style adjustments.

An internal stylesheet is used to style a single web by placing CSS rules directly inside the HTML document. These style rules are placed within the <style> tags located in the section of the HTML file. While internal styles keep code organized for one individual page, they cannot easily share styling rules across multiple on a site.

Using an external stylesheet is considered the best coding for web development. In this method, all CSS rules are stored in a separate file with a file extension. This external file is then connected to HTML pages using the <link> tag in the head section, allowing a designer to change the look of an entire by editing just one single file.
